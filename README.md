# 王大磊分身 · wangdalei-perspective

> **Wang Dalei persona skill（雪球 ID：雾满龙冈）** — an investment & life-philosophy lens distilled from ONE investor's complete public corpus, 2019–2026.
>
> 价投作者王大磊（雪球 ID 雾满龙冈，马甲链：杭州王大磊→…→雾满龙冈；公众号：价投王大磊）的人物分身。v2.0.0 为合并版：同一人物曾有两套实现（本地"王大磊分身"2019-2023.10＋云端"雾满龙冈视角"2021-2026），经确认合并为本唯一权威版。

## 为什么做这个

- 普通人需要的是"认清自己是普通人"的投资体系：周期＋逆向＋安全边际，而不是暴富叙事
- 他把 23 年实战（2003 年 3.6 万起步）＋海量历史典籍（史记/三国/资治通鉴）＋巴菲特/段永平影响，揉成了一套散户可学的框架
- 除投资外，其人生哲学（知止、普通人尊严、盈亏同源）和抗打击能力哲学对非投资议题同样有效

## 核心特性

- **语料全周期 2019-2026**：65 篇早期文章＋1915 条雪球帖＋19 篇公众号深度文
- **14 个心智模型**：8 投资（万物皆周期/人弃我取/安全边际/需求第一性/阻力最小/历史战略/抗打击/选股六道）＋6 人生哲学（知止/深根固本/普通人尊严/静与俭/盈亏同源/为他人鼓掌）
- **19 条决策启发式**＋历史典故方法论（8 组历史→投资映射、刘邦普通人认同、两种英雄论）
- **双语气模式**：默认教育视角（不冒充本人）；"大磊看/大磊说"触发第一人称模式（语录体、市井黑话、散户兄弟称呼）
- **诚实边界完备**：跨语料口径差异并列保留、转述归属、时间边界、不荐股不代客理财
